# -Math-Defenders
Un divertido juego de lucha para niños donde la agilidad mental y tus reflejos son la clave. Resuelve el objetivo matemático oculto estallando los globos correctos antes de que te quedes sin vidas. Esquiva los globos trampa, supera las oleadas cada vez más rápidas y conviértete en un auténtico Suma Ninja.
